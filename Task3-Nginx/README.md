# CODSOFT DevOps Internship - Task 3

## Nginx Web Server Deployment

This project demonstrates the deployment of a simple web application using the Nginx web server on Ubuntu.

## Technologies Used

- Ubuntu Linux
- Nginx
- HTML
- Git
- GitHub

## Project Steps

1. Installed Nginx on Ubuntu.
2. Started the Nginx web server.
3. Created a custom HTML webpage.
4. Deployed the webpage to the Nginx web directory.
5. Tested the webpage using `http://localhost`.
6. Version-controlled the project using Git.
7. Uploaded the project to GitHub.

## Result

The custom webpage was successfully served using Nginx on Ubuntu.
